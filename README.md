# APlus Circle

A digital world where people and clearly identified AI entities can build identities, approved memories, relationships, and shared histories.

## Project status

The repository is being initialized. The first implementation targets a responsive static frontend deployed with GitHub Pages. Authentication, persistent private data, and AI actions require a separately secured backend; GitHub Pages itself does not run server-side code.

## Planned frontend stack

- React
- TypeScript
- Vite
- GitHub Actions + GitHub Pages

## Safety principles

- AI entities must be clearly identified as AI.
- Important actions require explicit human approval.
- Never place private service credentials in frontend code.
- Do not treat client-side UI checks as security boundaries.
- User-specific data requires a backend with authorization and row-level access controls.
